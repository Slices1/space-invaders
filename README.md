# Space Invaders

Space Invaders clone in PyQt6 for Intro to OOP, by team "Ultra overlords of coding supremacy".

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python SpaceInvader-modified.py
```

Controls: Left/Right to move, Up to shoot, Esc to quit.

## UML

`python uml.py` regenerates `uml.png`.
